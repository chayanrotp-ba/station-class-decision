01 / CLASSIFICATION LOGIC

จัด Class ตามลำดับ เพื่อไม่ให้นับซ้ำ

เลือกได้ 9 / 17 / 35 / 51 จุด

ตรวจสอบกับ Excel (2): ชีต B >50 ระบุ 34 จุด และ B >40 ระบุ 50 จุด; ผลในรายงานเพิ่ม 1 จุด เพราะคำนวณ Class A ของชัยนาทใหม่โดยเลือกสีแดงก่อน แล้วจุด A เดิมคะแนน 59.63 กลับเข้าสู่ Class B

05 / DECISIONS TO MAKE

ประเด็นที่เสนอให้ผู้บริหารตัดสินใจ

1. เลือกความเข้มของเกณฑ์ B

คง A ไว้ 20 จุด แล้วเลือก B เพิ่ม 9, 17, 35 หรือ 51 จุด ตามเกณฑ์ที่เหมาะสมกับวงเงินและการครอบคลุมพื้นที่ โดยยังไม่มีข้อมูลต้นทุนในชุดนี้

2. พิจารณา C เป็นรายจุด

ตรวจเหตุผลเชิงพื้นที่กับภัยหลัก/รอง ยืนยันประโยชน์การเตือนภัย ช่องว่างข้อมูลจริง และความพร้อมติดตั้งกับจังหวัด ก่อนสรุปเลือกหรือไม่เลือก

3. ยืนยันจำนวนหลัก–สำรอง

เป้าหมายใน PDF คือหลัก 70 และสำรอง 15 แต่ Excel มีหลัก 69 และสำรอง 16 การจัด Class ไม่ได้เปลี่ยนสถานะเดิม ต้องยืนยันรายการสุดท้ายก่อนกำหนดแผนสำรวจ
