# การจัดลำดับสถานีตรวจวัด 85 จุด

เว็บปัจจุบันมีรายงาน แผนที่ ArcGIS World Imagery และเมนู Master สำหรับชื่อ หมายเหตุ และรูปภาพหลายรูปต่อจุด ข้อมูลแก้ไขเก็บใน D1 และไฟล์รูปเก็บใน R2 ของ Sites รูปต้องอัปโหลดผ่านเว็บที่เผยแพร่ ไม่เก็บรูปไว้ใน localStorage

ไฟล์ `dist/index.html` และ ZIP จากรอบแรกเป็นรายงานออฟไลน์เดิมเท่านั้น รุ่นปัจจุบันอยู่ที่ `dist/client/index.html` และ `dist/client/master.html` พร้อม Worker `dist/server/index.js` และต้องเปิดผ่านเซิร์ฟเวอร์เพื่อใช้ Master/รูปภาพ

พิกัดบนแผนที่ยึด Excel ทุกจุด จับคู่กับรายการแนบใหม่ได้ 85/85 จุด พิกัดต่างกันหรือมีรูปแบบผิด 10 จุด (รวม อบต.ตาดควัน ซึ่งใช้ Excel 19.961848, 100.235827) เก็บชื่อและ UTM จากรายการแนบแยกจากพิกัดอ้างอิง ไม่คำนวณ Class ใหม่จากการแก้ชื่อ

บริการ GIS: เส้นน้ำหลัก layer 0, เส้นน้ำรอง layer 0, จังหวัด/อำเภอ/ตำบล layer 1 ตาม URL ที่ผู้ใช้ให้ ระบบใช้ Province_Gray ร่วมกับขอบเขตจังหวัด ปภ. เพื่อซ่อนจังหวัดนอกตัวเลือก แสดงจำนวนที่โหลดจริงและข้อผิดพลาด ไม่ตีความเส้นน้ำว่าเป็นทิศการไหล ชั้น Province_Gray มี 54 จังหวัดและชั้นจังหวัดมี 76 จังหวัด (ไม่มีสตูล) จึงประกอบรูปพื้นที่ 7 อำเภอของสตูลเป็น MultiPolygon พร้อมระบุที่มานี้ในหน้าเว็บ ไม่อ้างว่าเป็น geometry จังหวัดต้นฉบับ

เริ่ม local: `npm install`, `npm run build`, `node dev-server.mjs` (http://127.0.0.1:8765) ฐานข้อมูลและรูปทดสอบเก็บใน `.local-data` แยกจาก production โดย local server ใส่ผู้ใช้สำหรับ preview เท่านั้น Worker production ต้องมี authenticated header จาก Sites

ตรวจสอบ: `npm run check`, `npm test`, `node tests/browser.cjs`, `node tests/layers.cjs` ทดสอบ API ใช้ฐานข้อมูลชั่วคราวแยกต่างหาก ทดสอบ browser ลบเฉพาะรูป fixture ของตัวเองเมื่อเสร็จ ไม่แตะรูปจริง

ข้อมูลยึดจาก Excel ที่ได้รับ และใช้ PDF อธิบายวิธีประเมิน ผู้ใช้ยืนยันให้คำนวณ Class A ใหม่ด้วยสีแดงก่อนทุกจังหวัด

- ฐานข้อมูล: ชีต A แถว 2–21 รวมกับชีต C แถว 2–66 = 85 พิกัดไม่ซ้ำ 20 จังหวัด
- A: คะแนนสูงสุดในสีแดงของจังหวัด หากไม่มีสีแดงใช้สีส้ม = 20 จุด ไม่พบคะแนนสูงสุดเสมอ
- B: หลังหัก A ใช้คะแนน M > 70/60/50/40 = 9/17/35/51 จุด
- C: หลังหัก A คะแนน M < 40 = 14 จุด มีเหตุผลต้นฉบับครบ
- ไม่ตีความจุดที่ยังไม่ผ่าน cutoff B ว่าเป็น C
- เปลี่ยนตัวแทนชัยนาท: สำนักงานเทศบาลตำบลชัยนาท (แดง 35.41) เป็น A; สำนักงาน ปภ. จังหวัดชัยนาท (ส้ม 59.63) เป็น B
- สถานะตามรายการ: หลัก 69 สำรอง 16; เป้าหมายใน PDF: หลัก 70 สำรอง 15
- สีแดง 43 สีส้ม 42 ตรงกับ PDF หน้า 5
- ยึดคะแนนรวม M ไม่คำนวณใหม่จาก N/O ที่สลับกันระหว่างชีต

`extract_sources.py` อ่านไฟล์ต้นฉบับ (ไม่แก้ไข), `analyze.py` สร้างข้อมูลวิเคราะห์, `build.py` ประกอบ HTML, `qa.cjs` ตรวจปุ่มเกณฑ์ รายชื่อ ตัวกรอง รายละเอียด เอกสาร และ responsive

ผลตรวจรอบนี้บันทึกที่ `analysis/qa-results.json`.
